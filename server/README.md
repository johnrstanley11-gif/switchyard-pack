# Server

The Switchyard server runs NeoForge 26.3.0.65-beta with the mods in `MODS.txt` (the client packs plus server-only mods: Castle Guard, Community Bridge, Go Home Already, Lithium, Chunky, ServerCore, AntiXray, Simple Backups).

`server-icon.png` is the icon the server sends to the multiplayer list; the packs' `servers.dat` carries the same image.

Server configuration files are not published: they contain the world seed, API tokens and vote-listener keys. The gameplay rules they set are described on the website: https://mc.jorry.live/page/server-info
